# 流行音樂 4536 和弦進行教學 (TMD Interactive Music Tutorial)

歡迎來到 TMD 互動樂理教學！這份 Markdown 文件展示了如何使用 TMD 語法記錄流行音樂中最經典的和弦進行。
在 VS Code 中按下 `Cmd+Shift+V`（或 `Cmd+K V`）開啟 Markdown 即時預覽，即可直接隨點即播、聆聽合成音訊！

---

## 1. 什麼是 4536 和弦進行？

4536 和弦進行（IV - V - iii - vi）是華語流行音樂、J-Pop 與動漫音樂中最常見的副歌走向之一。
在 C 大調中對應為：**F - G - Em - Am**。

### 示範 1：基礎 4536 三和弦

點擊下方播放列的 **▶ Play** 按鈕即可離線試聽：

```tmd
::SCORE::
** 4536 基礎三和弦 **
!= 120
?= C
<4/4>

chorus:Piano@|0|{
    <4*>
    | [4] - - - | [5] - - - | [3m] - - - | [6m] - - - |
}

chorus:Bass@|0|{
    <4*>
    | 4_ - - - | 5_ - - - | 3_ - - - | 6_ - - - |
}

-> chorus ->#
```

## 2. 升級為流行七和弦（4maj7 - 57 - 3m7 - 6m7）

如果想要更有流行、R&B 或都會感，通常會將 IV 級與 I 級加上大七度，V 級加上屬七度，小和弦加上小七度：

```tmd
::SCORE::
** 4536 流行七和弦進階版 **
!= 108
?= C
<4/4>

verse:Piano@|0|{
    <4*>
    | [4maj7] - - - | [57]  - - - | [3m7] - - - | [6m7] - - - |
}

verse:Lead@|0|{
    <4*>
    | 1^ 7 6 5 | 7 6 5 4 | 5 4 3 2 | 3 - - - |
}

-> verse ->#
```

## 3. 簡短樂段片段（Bare Snippet）

TMD Markdown 播放器也支援不用寫完整 `::SCORE::` 檔頭的片段語法，適合快速分享動機：

```tmd
riff:Guitar@|0|{
    <8*>
    | 1 3 5 1^ 7 5 3 1 | [4] - - - - - - - |
}
```

> **提示**：點擊卡片上的 **`✏️ Try in Editor (嘗試編輯)`**，可以直接在側邊分頁打開樂譜動手修改與試聽！
